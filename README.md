## Design System

📄 Zeroheight: https://lnkd.in/drC2nK84

🎨 Figma: https://lnkd.in/dWq_E3EJ

| Element | Suggested Color | HEX | Reason |
| :--- | :--- | :--- | :--- |
| Main Background | Off-White / Soft Cream | `#F9F9F9` | Less visual fatigue than pure white (#FFFFFF). |
| Base Text | Graphite Black | `#1A1A1A` | Maximum elegance and contrast superior to 15:1. |
| Primary Color | Deep NYC Blue | `#003566` | Meets AAA on light background; sober and serious. |
| Accent Color | "Empire State" Gold | `#C5A059` | Adds the "elegant" and premium touch. |
