## Declaración de Accesibilidad para GEK

### Nuestro Compromiso

En **GEK**, creemos que la web debe ser un espacio sin barreras. No solo diseñamos para la vista, sino para la experiencia humana en toda su diversidad. Nos hemos fijado el estándar más alto posible, utilizando el **NYC Design System** como base, para demostrar que la elegancia y la inclusión total pueden (y deben) coexistir.

### Estado de Cumplimiento

Estamos trabajando activamente para alcanzar y mantener los siguientes niveles de conformidad con las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2:

* **WCAG 2.2 Nivel AA:** Cumplimos actualmente con el **95%** de los criterios.
* **WCAG 2.2 Nivel AAA:** Cumplimos actualmente con el **75%** de los criterios, priorizando el contraste de color avanzado y la facilidad de lectura.

> **Nota técnica:** Aunque aspiramos a la perfección, reconocemos que la accesibilidad es un viaje continuo. Algunas herramientas de terceros o contenido histórico en el blog podrían presentar desafíos que estamos resolviendo activamente.

### Especificaciones Técnicas

Para garantizar la mejor experiencia, GEK se apoya en las siguientes tecnologías:

* **HTML5** semántico para una estructura lógica.
* **WAI-ARIA** para mejorar la navegación con lectores de pantalla.
* **CSS** con enfoque en `prefers-reduced-motion` y tipografía responsiva.

### Medidas de Apoyo a la Accesibilidad

Hemos integrado las siguientes funciones para mejorar tu navegación:

1. **Navegación por Teclado:** Todos los elementos interactivos tienen un indicador visual de enfoque claro y elegante.
2. **Jerarquía de Contenido:** Estructura de encabezados lógica para facilitar la lectura rápida.
3. **Contraste Elevado:** Una relación de contraste de al menos **7:1** en todo el texto principal.
